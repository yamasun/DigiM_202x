# DigiM 2022

This repository contains three standalone Japanese HTML presentation decks about digital marketing and IoT, plus a small landing page that links to each deck.

## Running on Replit

The project uses Python's built-in static file server; no package installation or environment variables are required.

```bash
python3 -m http.server 5000 --bind 0.0.0.0
```

Open the Replit preview to use the deck selector. The presentation files load Tailwind CSS, Font Awesome, and Google Fonts from public CDNs, so an internet connection is needed for their full styling.
